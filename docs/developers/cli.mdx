Use this page to choose a command. The [CLI reference](/packages/cli) contains
detailed flags, examples, and environment settings. The installed version
remains authoritative: run `npx smashcut <command> --help`.

## Everyday project loop

| Task | Command |
| --- | --- |
| Create a project | `npx smashcut init my-video` |
| Open Studio | `npx smashcut preview` |
| Check HTML structure | `npx smashcut lint` |
| Run browser, layout, motion, and contrast checks | `npx smashcut check` |
| Capture review frames | `npx smashcut snapshot --at 0,2,5` |
| Render a video | `npx smashcut render --output output.mp4` |
| Publish a browser link | `npx smashcut publish` |
| Diagnose the machine | `npx smashcut doctor` |

## Work with media

| Task | Command |
| --- | --- |
| Inspect project metadata | `npx smashcut info` |
| Transcribe speech | `npx smashcut transcribe <file>` |
| Generate narration | `npx smashcut tts <script>` |
| Capture a website | `npx smashcut capture <url>` |

## Reuse and inspect

| Task | Command |
| --- | --- |
| Add a Catalog item | `npx smashcut add <name>` |
| List compositions | `npx smashcut compositions` |
| Inspect keyframe behavior | `npx smashcut keyframes` |
| Compare two or more versions | `npx smashcut compare v1/ v2/` |

## Rendering and automation

The CLI also renders in batches and from variables, writes image sequences and
several video formats, and runs in the cloud — managed, on AWS Lambda, or on
Google Cloud Run. Most commands take `--json` when you need to read the result from a script.

Start with the simple command, then open the [full reference](/packages/cli) for the exact options needed by automation or infrastructure.

<Tip>
  Run `npx smashcut <command> --help` for the installed version’s exact syntax.
</Tip>
